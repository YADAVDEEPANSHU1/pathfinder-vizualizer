# Pathfinding Visualizer (C++ Console Application)

This is a console-based pathfinding visualizer developed in C++. It allows users to set a start point, an end point, add obstacles to a grid, and visualize the grid layout directly in the terminal. This project serves as a solid foundation for implementing pathfinding algorithms such as BFS, DFS, A*, and Dijkstra.

## Features

- Set custom start and end points
- Add obstacles to the grid
- Display the current grid state
- Reset the grid to its initial configuration
- Modular design using object-oriented principles
